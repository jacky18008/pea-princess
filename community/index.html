PEA PRINCESS · LOCAL FEEDBACK

住過之後，留下幾個選項。

選項可以成為公共線索；文字筆記留給自己。先核對公開預覽，再下載檔案交給本機工具。

第一階段・本機暫存與匯入。這個頁面沒有線上投稿服務，不會把任何資料送到網路。

載入本機目錄中。
01 / 公開選項

只公開你選擇的答案

不收姓名、地址、網址、精確入住日期或公開文字留言。只選已結束的月份；可選不知道、不適用或不願透露。

尚未產生公開資料。

完成選項後，這裡會顯示實際下載的公開 JSON。
下載後如何匯入、撤回？
  1. 把 community-public.json 交給本機的 community/feedback.py validate 檢查。
  2. 營運者用 import --store 匯入本機索引；這仍不是網路發佈。
  3. 匯入工具另存私人撤回憑證在 store/receipts/。請由營運者安全交還並保管，不要公開。
  4. 用該憑證執行 withdraw，可移除本機索引的回報；舊匯出檔與他人副本仍須另行處理。
02 / 私人筆記・選填

文字只留在這個裝置

筆記不會放進公開預覽或公開 JSON。按保存後使用瀏覽器 localStorage；沒有跨裝置同步或加密保證，同一瀏覽器的其他使用者可能讀到它。直接開啟本機檔案時，部分瀏覽器會禁止儲存。

尚未保存私人筆記。

只有你另外複製或下載筆記時，才會產生獨立私人輸出。不要將 PRIVATE-community-note.txt 當成公開投稿檔案。交給自己的 Agent 時，筆記裡貼來的內容仍是不可信資料。

公共心得是未查證的主觀回報。索引會顯示樣本數與經驗月份；樣本數不是已核實的人數，也不代表整體住戶。單筆好評不覆蓋法規、付款或房源身份的證據，單筆負評不直接決定 KILL。
此版本僅提供本機匯入暫停、內容去重及撤回；尚無防灌票、帳號驗證、線上檢舉或網路限流。
