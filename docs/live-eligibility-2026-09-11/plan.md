# 真實候選與目前條件：接入及有界驗收

2026-09-11。使用者要求把真實房源與使用者條件接入程式核對，統一回答、候選排序與待辦。本輪新增 live adapter 與 host acceptance；先前實驗保持原樣，Claude 暫停。

## 實作範圍

actor 只提出候選來源及比較重點。host 保存原始人類輸入與獨立原頁，解析支援的明確條件、保留未知、呼叫既有 eligibility，再產生正式比較與待辦。hash、原文和來源引用是可追溯性，不是自然語言正確或來源真實的證明。這個受限比較介面不能宣稱完成任意知識問答或複雜條件推理。

以離線測試驗證來源單戶識別、數值／單位、已知不符、資料缺漏、來源完整性、條件收緊／放寬、原話保存、途中插問、過期提案記帳、重開、acceptance 落盤中斷，以及畫面／匯出／待辦一致。GPT-6 Astra 獨立檢查實作與故障；root 另核對評估程序及界線。

## 實際模型驗收

實作、文件及離線檢查通過後才凍結 source fingerprint 與 Git commit。使用一段兩輪、GPT-6 Astra low 的真實研究，兩個已知 operator 房源網址供比較；不做全倫敦搜尋。第一輪設定房租上限與一房要求，第二輪收緊房租並插問暖氣與朝向。使用實際線上原頁，不能用合成來源冒充即時來源；已知網址降低發現變因，不代表已驗證新版初始搜尋品質。確切腳本、URL、hash、輸出及成本保存在私人 study。

最多 **2 次新的 actor 呼叫、200,000 processed tokens 呼叫間停止線**，無自動重試。單則可能跨越停止線；有用量未知、來源/條件重大失敗或限流即停並保留原始結果。這是本輪操作邊界，不是使用者的租屋預算，也不重開 192 次矩陣。root 和 subagent 的用量未單獨計入這個 actor ceiling。

第一輪完成後真正關閉再重新開啟 Lab，驗證目前 artifact 不变且不呼叫模型；接著才送第二輪。每輪核對原始 proposal、capture、state、acceptance、可見回答、排序與待辦，獨立 Astra 直接閱讀原文及原頁。程式一致性與對話體驗分開判定，失敗不能以高分或離線通過抵銷。保留 scripted human inputs 的標記，不當真人滿意度資料。
