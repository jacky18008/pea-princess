# Rental portals: access and licensing audit

Checked **11 September 2026** for a permanently free, local installable skill run by each user’s own agent. This reviews provider wording and official interfaces; it does not determine whether a particular contract is enforceable or conduct is unlawful. No accounts, contacts, payments, listing API requests, crawler tests, model experiments or runtime changes were made.

The evidence register is [portals.json](portals.json). Every provider has dated official links, clause references, separate access/read/reuse/API/alert findings, eligibility and fee unknowns.

| Provider | Automated discovery / user-directed agent | Content/report use | Official no-paste candidate |
|---|---|---|---|
| [Rightmove](https://www.rightmove.co.uk/c/terms-of-use/) | Broad restriction; direct-human wording, §§5.2, 5.5. | Offered-download allowance is narrow; software linking/assets also restricted, §§8.3, 13.4–13.5. | Personal alert emails; separately authorised original-agent source. |
| [Zoopla](https://www.zoopla.co.uk/terms/) | Automated methods restricted, with applicable-law qualification. | Personal extracts do not clear the automation step. | Announced official Zoopla ChatGPT app; current account availability untested. Saved-search email/push and independently permitted agent sources remain candidates. |
| [OnTheMarket](https://www.onthemarket.com/terms/) | §3.3 expressly excepts qualifying Permitted Programs. | Separate storage/reproduction/linking restrictions remain. | Conditional compliant reader, or official alerts; further report-use assessment needed. |
| [OpenRent](https://www.openrent.co.uk/terms) | Harvesting restricted; isolated assistive reading not expressly classified. | Copying needs permission. | Official personal alerts; direct-landlord alternative only if available. |
| [SpareRoom](https://www.spareroom.co.uk/content/default/terms-uk/) | Harvesting and unapproved integrations restricted. | Personal-use conditions restrict reproduction in other works. | Official personal alerts; independent advertiser source where available. |

**These candidates are not a completed licensed integration.** A user-authorised mail connector can remove the copy-and-paste step, but the reviewed alert pages do not expressly license external automated extraction, storage or report reuse. The skill must not silently turn alert links into permission to fetch the portal. Receiving alerts also does not guarantee a complete current catalogue.

OnTheMarket merits a separate feasibility assessment: its access exception requires unique program identification and full compliance with the [current robots rules](https://www.onthemarket.com/robots.txt). Many useful filtered queries and some asset/redirect routes are excluded. No actual agent host or URL sequence was tested, and satisfying access conditions does not clear persistent copies or report links.

Rightmove’s [ADF documentation](https://www.rightmove.co.uk/adf.html) serves participating advertisers uploading their own listings. Zoopla’s verified [Premium Listings API](https://support.zoopla.co.uk/hc/en-gb/articles/360015664558-Premium-Listings-Tech-documentation) activates a customer product. OnTheMarket’s [feed guidance](https://www.onthemarket.com/content/how-to-use-only-with-us-to-draw-serious-attention-to-your-property-listings/) also describes advertiser uploads. None establishes a free consumer API for searching everyone’s rentals. OpenRent and SpareRoom search-API eligibility, and any relevant licence prices, remain unknown. Zoopla’s developer homepage produced no readable body, so this audit makes no claim that its old public API is currently available or definitively retired.

For the no-paste product, the concrete routes to assess are: official alerts into the user’s authorised mailbox; separately permitted original-advertiser sources; OnTheMarket’s conditional access route; or a provider/data-supplier agreement explicitly covering local agents and the intended report use. An original landlord/agent page will not exist for every advert. Optional user-supplied documents remain useful, but neither pasting nor receiving a file automatically clears every subsequent reuse.

Official alert setup sources: [Rightmove](https://faq.rightmove.co.uk/support/solutions/articles/7000048758-how-to-register-for-property-alerts), [Zoopla](https://help.zoopla.co.uk/hc/en-gb/articles/360005969458-How-do-I-create-email-alerts-and-saved-searches), [OnTheMarket](https://www.onthemarket.com/content/how-to-use-onthemarkets-tools-to-conduct-the-best-property-search/), [OpenRent](https://help.openrent.co.uk/hc/en-gb/articles/360018359252-How-do-the-search-bar-and-email-alerts-work), [SpareRoom](https://www.spareroom.co.uk/content/info-faq/why-email-alerts/).

This is a documentation-only audit. Unknown access grants remain unknown, and it changes no source policy or runtime behaviour.
