# Estate agents and rental operators: source access audit

Checked **2026-09-11** for a permanently free, local skill using the user's own agent. This is a bounded evidence review, not a new source policy or a legal permission certificate. Machine-readable records: [agents-operators.json](agents-operators.json).

**None of these nine providers was verified as offering a public consumer inventory-read API or an express licence for the complete automated discovery → persistent snapshot → AI report workflow.** That is a search finding, not proof that no agreement or lawful basis is possible. Several sites expressly support narrower personal downloads, which can remove manual copying. A user choosing a file is different from an agent silently crawling or republishing it.

## What can actually reduce user effort

1. **Selected official downloads, then local file ingestion.** Foxtons has an indexed listing PDF interface; Dexters and Chestertons expressly allow limited personal downloads. A user can select/save a file instead of copying a page. AI retrieval, cloud transmission and derived output still need their own scope assessment; this review did not validate a complete zero-touch workflow.
2. **Ask once for an explicit integration scope, not permission from every renter.** Operator contact pages are recorded in JSON. A useful request would specify free local personal use, low request volumes, fields, short retention, private reports, image treatment and whether a user's chosen cloud model may process content. No contact was made and no grant is implied.
3. **Separate acquisition from factual analysis.** Preserve necessary source references, factual values and provenance without assuming indefinite full-page/image retention is allowed. Any change to retention must also preserve auditability; this report does not silently weaken the current evidence controller.

The [Foxtons PDF observation](https://www.foxtons.co.uk/properties-for-sale/e3/chpk1650614) came from the search index, not a new listing crawl or a current availability check. Chestertons' [relocation brochure](https://www.chestertons.co.uk/corporate-relocation) describes services, not a rental inventory feed. No public API fee or eligibility was established; JSON uses null, not zero/free.

## Robots and research limits

[Foxtons robots](https://www.foxtons.co.uk/robots.txt) excludes API/JSON/account paths and several search patterns. [Knight Frank robots](https://www.knightfrank.co.uk/robots.txt) and [Savills robots](https://www.savills.co.uk/robots.txt) contain path/query and named-agent restrictions. The other checked robots URLs failed in the web tool; none is labelled empty or allowed. No robots entry was interpreted as an IP licence.

Official terms, public help/contact pages and indexed documentation were reviewed. No listing pages were opened, brochures downloaded, account created, message sent or model experiment run. Seven providers supplied relevant terms text, Savills remained inaccessible, and Fizzy supplied only promotion terms. JLL's residential scope remains uncertain. Some source text came from the official search index rather than a successful fresh page open. This report retains paraphrases and URLs, not immutable full-page legal snapshots; recheck changed terms before implementation.
