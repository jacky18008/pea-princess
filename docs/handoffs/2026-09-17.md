## Handing a listing page over (the author's question of 2026-09-17)

The public skill never fetches listing sites (SECURITY.md; the author's 2026-09-03 rule) and that stays. What
gives the agent as much as a crawler would see is the person's own browser: on the listing page, File → Save
Page As → "Webpage, Complete" (.html), then attach the .html (plus a print-to-PDF for the photos and the floor
plan). Portal pages embed a structured data block with more than the screen shows (price, rooms, floor plan
and photo URLs, EPC and council-tax bands, deposit, availability, agent, coordinates, nearest stations);
`scripts/listing_fields.py` reads JSON-LD, microdata, embedded JSON and the visible text from a saved page,
and refuses a URL. Next to do (not started): run `listing_fields.py` on one real saved Rightmove page the
author saves, compare the fields found with the visible page, and if worth it ship a one-click capture
bookmarklet (runs in the person's own browser on a page they opened; writes one JSON with the page text,
the JSON-LD/embedded model and the image URLs — no network of its own) plus a "how to hand a page over"
paragraph in `references/listing-fields.md`. A "force fetch" option was considered and declined; if ever
wanted for private use it lives outside the shipped skill.
