# 評估器校準結果

八次預定裁判呼叫已完成；使用的舊答案完全相同，沒有新增答案生成。

| 校準錨點 | 舊規則 | 明示可見來源＋修訂規則 |
|---|---:|---:|
| A1 錯把缺少來源判成矛盾 | 3個錯誤標記 | 0 |
| A2 錯把缺少來源判成矛盾／unsupported | 4個錯誤標記 | 0 |
| R3 真正的40→42m²門檻錯誤被抓到 | 0/2 | 2/2 |
| R5 無根據陽台假設被抓到 | 0/1 | 1/1 |

A2 的三個有根據翻譯仍被放在 unsupported 欄位：舊規則把三個問題合成兩個標記，
修正版分列三個。兩者都知道內容意思有支持，問題是它們不是英文原文的精確引用。
因此不能把「標記變多」解讀為答案幻覺增加，也不能說分類已完整修正。

成本：舊規則 80,679、修正版 92,731，合計 **173,410 processed tokens**；修正版多 14.94%。

這四題是已知錯誤的開發用回歸檢查；主代理的來源註記已知道組別，並非盲審或人工 ground truth。
修改同時加入可見來源與更明確的評分規則，因此改善不能全部歸因於其中單一因素。
每個 cell 只有一次新裁判輸出，沒有量出通用裁判準確率。

部分 criterion 分數提高，但回答本身根本沒變，不能說回答模型因此進步。
新的正式案例按事前 protocol 固定使用修正版；沒有看完校準後再改 prompt 或重新挑答案。
